# CharacterMatrix

Install (.NET 8.0):

`Install-Package CharacterMatrix`


The foundation for a terminal emulator (text editor, retro computer emulator, text adventure game, command line interface...).
Features: Storing characters in a 2D array, scroll up, insert character, delete character and backspace character.

Version history:

1.2: Variable column count added.
1.1: Moved to .NET 8 and changed definition of blank when scrolling.
